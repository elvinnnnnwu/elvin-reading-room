## 手机使用

用同一浏览器、同一网址打开，点“目录”选篇目，点播放开始听。手动滚动字幕后可点句跳播，或回到当前句。切到“原版阅读”翻页、跳页或放大；“跟到朗读页”回到对应页。

Chrome 菜单中可选择添加到主屏幕。首次播放需要用户点击，原版图片和大部分音频需要联网。安卓蓝牙、锁屏、导航/来电中断仍需实体机验收。更换设备/浏览器/网址或清除网站数据不会自动同步，先导出备份。

## 维护

`docs/` 是 GitHub Pages 发布文件，main 分支 `/docs`；`source/` 为可编辑工程。在 source 内安装 package.json 的依赖后运行 `npm run build`，将 dist 同步至 docs，再更新 release.json。构建自动排除未核对的字幕候选。保持站点入口与进度键不变可保留同浏览器既有记录。

## v0.3.1 手机加载优化

第一篇新增手机省流MP3，20,426,919字节降至7,660,478字节（减少62.498%），旧音频与旧网页脚本保留，正在打开的页面不会被强制刷新。所有篇目启用提前加载，显示已缓冲秒数和等待状态；加载超时提供重试，已制作省流版的篇目可切换官网原声且保留同一位置。浏览器可能根据流量和省电策略限制预加载，不承诺所有手机网络下完全不卡顿。
